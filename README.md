Yes. I’ve structured KAF Eatables as a **WhatsApp-first food ordering site** rather than a traditional ecommerce checkout.

### What’s built

* **Hero:** Small Chops • Burger • Shawarma • Sandwich
* **Menu categories:** All, Small Chops, Burger, Shawarma, Sandwich
* Product cards with images, descriptions, prices and quantity controls
* **Cart drawer**
* Automatic order total
* **“Send order on WhatsApp”** generates a formatted WhatsApp order
* Event catering section
* “We are available to travel” messaging
* Direct call links:

  * 0905 355 1681
  * 0812 526 1879
* Instagram link
* Mobile-friendly layout
* Sticky navigation
* Mobile floating order button
* No account creation
* No payment gateway
* No complicated checkout — **the conversation happens on WhatsApp**

I also looked at current Nigerian food-ordering patterns while structuring the UX; direct menu ordering and WhatsApp-style ordering are already familiar patterns in this market. ([Take App][1])
